# Public source release — 2026-11-18

This repository contains the current local Clinime Customer and Staff applications, their server modules and tests, portable brand/image/font inputs, design-system sources and engineering reference documents.

The source was staged from the 2026-11-15 engineering handoff and refreshed with the current local client/server/tests. The public release adds an isolated, no-login demo server. It does not alter the live clinic or its authentication.

Historical exploration releases, old archives, live provider credentials, customer exports, private evidence, account caches and dependency folders are intentionally excluded. They are not required to run the accepted interfaces.

Engineering reference documents describe the broader existing system and may mention previous environments or historical checks. Use the root README and demo guide for this release; historical checks are not proof that a fresh installation passed.

Source and assets retain their existing authorship/provenance. The repository does not grant rights to use Clinime trademarks or third-party assets beyond their own terms. Included font/icon license files remain authoritative. No third-party provider account is included.
